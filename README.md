# マイクラ新情報ウォッチ

Java版・統合版の新要素を見張って、出たらすぐスマホ（Discord）に通知します。
解禁予想と実際の公開日は Google カレンダーで見られます。

## 何が届くか

| 通知 | いつ | 中身 |
|---|---|---|
| 🆕 新要素あり | スナップショット／ベータ・プレビューに新しいブロック・アイテム・モブ・仕組みがあるとき | 新要素の一覧（日本語要約と動画タイトル案はオプション） |
| 🎉 正式リリース | ドロップの正式配信（Java版・統合版） | 同上 |
| 🔄 仕様変更あり | 新要素は無いがゲーム内容の変更があるとき | 主な変更の一覧 |
| 📢 公式発表 | minecraft.net の記事でドロップ名・新要素・Minecraft Live などが出たとき | 記事の概要 |
| 🔧 修正のみ／📰 その他の記事 | バグ修正だけの回、ゲーム内容に関係が薄い記事 | 小さく通知（別チャンネルに分けるか、通知しない設定にもできる） |

マーケットプレイス・Realms・保護者向けガイドなどの記事は通知しません。

見張っている情報源（どれも Mojang 公式）:
- Java版: Minecraft Launcher のパッチノート（スナップショット・プレリリース・正式版）
- 統合版: feedback.minecraft.net の「Beta and Preview」「Release Changelogs」
- minecraft.net の記事 RSS

10分おきに確認します。Java版のスナップショットはだいたい火曜 20:30〜23:00、統合版のプレビューは火曜 23:00〜翌1:00（日本時間）に出ます。

## はじめ方（30分くらい）

### 1. Discord で通知先を作る

1. Discord で自分用のサーバーを作る（すでにあればそれでOK）
2. 通知用のテキストチャンネルを作る（例: `#マイクラ新情報`）
3. チャンネル名の横の ⚙（チャンネルの編集）→「連携サービス」→「ウェブフック」→「新しいウェブフック」
4. 「ウェブフックURLをコピー」を押す。**このURLは他人に見せないこと**（知っている人は誰でも投稿できてしまう）
5. スマホの Discord アプリで、そのチャンネルを長押し →「通知設定」→「すべてのメッセージ」

修正のみの回を別にしたいときは `#マイクラ-修正` なども作って、同じようにウェブフックURLをコピーしておきます（任意）。

### 2. GitHub にアップロードする

1. https://github.com でアカウントを作る（無料）
2. 右上の「＋」→「New repository」
   - Repository name: `mc-update-watcher`
   - **Public** を選ぶ（Public なら GitHub Actions が無料・無制限。ウェブフックURLなどの秘密は手順3で別に保管するので公開されません）
   - 「Create repository」
3. 作ったページの「uploading an existing file」を押し、このフォルダの中身（`.github` フォルダごと全部）をドラッグ＆ドロップ →「Commit changes」
   - `.github/workflows/watch.yml` が入っているか確認してください。入っていないと動きません

### 3. 秘密の設定を入れる

リポジトリの「Settings」→「Secrets and variables」→「Actions」→「New repository secret」

| Name | Secret | 必須 |
|---|---|---|
| `DISCORD_WEBHOOK_URL` | 手順1でコピーしたURL | 必須 |
| `DISCORD_WEBHOOK_URL_MINOR` | 修正のみ用チャンネルのURL | 任意 |
| `ANTHROPIC_API_KEY` | Claude API のキー（日本語要約と動画ネタを付ける） | 任意 |

修正のみの回を通知しないときは、同じ画面の「Variables」タブで `NOTIFY_MINOR` を `false` にします。

### 4. 動かす

1. 「Actions」タブを開き、緑のボタン（I understand my workflows…）があれば押す
2. 左の「マイクラ新情報ウォッチ」→「Run workflow」→「Run workflow」
3. Discord に「✅ マイクラ新情報ウォッチを開始しました」が届けば成功。以後は10分おきに自動で動きます
4. 通知の見た目を確かめたいときは、「Run workflow」で **テスト通知を送る** にチェックして実行（最新の各1件が届きます）

### 5. Google カレンダーに入れる

1. パソコンのブラウザで Google カレンダーを開く
2. 左の「他のカレンダー」の「＋」→「URL で追加」
3. 次のURLを入れて「カレンダーを追加」（`ユーザー名` は自分の GitHub のユーザー名）

   ```
   https://raw.githubusercontent.com/ユーザー名/mc-update-watcher/main/calendar.ics
   ```

4. スマホの Google カレンダーアプリの設定で、追加したカレンダー「マイクラ新情報（解禁予想）」の同期をオンにする

カレンダーに入るもの:
- 📡 毎週火曜の新情報タイム（10分前に通知）
- 🔮 解禁予想（本命・対抗の日付と理由つき）と 📝 動画準備のリマインダー
- 🎉🆕🔄📢 実際に公開されたもの（あとから振り返れる）

Google カレンダーの更新は数時間〜1日ほど遅れます。すぐ知りたい情報は Discord で、カレンダーは予定を立てる用です。

## 解禁予想を書き換える

`forecast.json` を GitHub 上で開き、鉛筆マークで編集して保存すると、次の実行（10分以内）でカレンダーに反映されます。
公式に配信日が発表されたら、`confidence` を `"確定"` にして日付を直すのがおすすめです。

## 費用

- GitHub Actions: Public リポジトリなら無料
- Discord: 無料
- Claude API（任意）: 要約1回あたり数円〜十数円。週に数回なので月に数百円程度

## 注意

- GitHub は、リポジトリに60日間動きが無いと定期実行を止めることがあります。この仕組みは新情報のたびに記録を保存するので普通は止まりませんが、止まったら「Actions」タブで再開してください
- 新要素の判定は変更履歴の見出しと書き出し（Added / Fixed など）で機械的に行っています。たまに外れるので、気になる回はリンク先の原文を確認してください
